# 3D Unswept Wing Aerodynamic Analysis in MATLAB

## Overview

This project implements a nonlinear lifting-line method in MATLAB to analyse the aerodynamic performance of a finite, unswept aircraft wing.

The method accounts for the three-dimensional effects produced by the finite span of the wing, including induced downwash, local effective angle of attack, wing taper, and spanwise twist. The circulation distribution is solved iteratively using the viscous aerodynamic characteristics of the selected airfoil section.


## Method

The wing is discretised into a number of spanwise panels, with a horseshoe vortex associated with each panel. The circulation strength of each vortex is related to the local sectional lift coefficient.

For each iteration:

1. The wing is discretised into `N` spanwise panels.
2. The local chord and twist angle are calculated.
3. An initial circulation distribution is assumed.
4. The induced downwash at each wing section is calculated using the Biot–Savart law.
5. The local effective angle of attack is determined.
6. Sectional lift and drag coefficients are obtained from the airfoil data using interpolation.
7. The circulation distribution is updated.
8. A damping factor is applied to aid convergence.
9. The process is repeated until the circulation distribution converges.

Once converged, the resulting spanwise lift distribution is used to calculate the overall 3D wing lift and drag coefficients, `CL` and `CD`.

## Features

The MATLAB program supports three analysis modes:

* **Mode 1:** Analyse a single angle of attack and a specified number of spanwise panels.
* **Mode 2:** Analyse a range of angles of attack for a fixed number of panels.
* **Mode 3:** Investigate the effect of spanwise discretisation by varying the number of panels.

The program also:

* Loads airfoil `Cl` and `Cd` data from an external data file.
* Accepts user-defined wing geometry and flight conditions.
* Iteratively solves for the spanwise circulation distribution.
* Calculates the local lift distribution.
* Calculates the 3D wing `CL` and `CD`.
* Generates plots for the different analysis cases.
* Saves numerical results to formatted text files.

## Aircraft Case Study

The project includes an aerodynamic analysis of a Piper PA-28-180 Cherokee wing using the sample configuration specified in the coursework.

### Wing parameters

| Parameter           |        Value |
| ------------------- | -----------: |
| Wing area, `S`      |     14.86 m² |
| Aspect ratio, `AR`  |         5.63 |
| Taper ratio, `λ`    |         0.95 |
| Tip twist, `ε_tip`  |          −3° |
| Airfoil             | NACA 652-415 |
| Altitude            |       1000 m |
| Freestream velocity |       45 m/s |

The analysis investigates both the variation of aerodynamic coefficients with angle of attack and the effect of changing the number of spanwise panels.

## Results

The generated results include:

* Spanwise lift distributions at different angles of attack.
* Comparison of lift distributions for different numbers of spanwise panels.
* 3D wing lift coefficient, `CL`, over a range of angles of attack.
* 3D wing drag coefficient, `CD`, over a range of angles of attack.
* Formatted numerical output for the analysed cases.

The results demonstrate how the predicted aerodynamic performance and spanwise lift distribution depend on both angle of attack and spanwise discretisation.

## MATLAB Implementation

The program is designed so that the main aerodynamic analysis can be run from the MATLAB script. Airfoil data and user-defined wing parameters are supplied as inputs, allowing the method to be applied to different wing configurations and flight conditions.

The implementation uses iterative convergence with damping to improve numerical stability.
